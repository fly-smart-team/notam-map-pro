# 공항 AMM 캡처 → 고해상도 지도 추가 절차

1. `twy/index.json` `airports.ICAO.amm.bbox` = [서, 남, 동, 북] (공항 전체가 들어가게, 0.02° 단위로 OSM 요청)
2. 앱(브라우저)에서 `await ammFetch('ICAO', bbox)` → OSM 공항 자료를 받아 기기에 저장, 이름 있는 유도로 목록 확인
3. 캡처를 `m1.png…` 로 두고 `python3 amm_ocr.py` → 검정 상자 안 노랑 글씨(유도로 이름)와 픽셀 위치(ocr.json). 범위(x·y 한계)는 캡처 크기에 맞춤
4. 앱 콘솔에서 위치 맞춤(투표 방식): 이름이 OSM에 있는 이름표마다 그 유도로 위의 점들로 원점 후보를 계산해 가장 많이 겹치는 곳 선택, 축척 1.0~1.35 m/px 탐색
   → OSM에 없는 이름표는 위·경도로 바꿔 `names`, 핫스폿(주황 표지)은 `hs`(pt 또는 line)
5. 공식 기준은 각국 AIP AD 2.24(비행장 차트·핫스폿). 받으면 핫스폿 번호·설명을 AIP로 맞춤
